# Palavra Mágica

## Sobre o projeto

O Palavra Mágica é um jogo educativo desenvolvido como projeto acadêmico da disciplina de **Projeto e Design de Interfaces**.

O jogo é voltado para crianças e adolescentes em fase de alfabetização e aprimoramento da leitura e escrita, buscando estimular o raciocínio linguístico e ampliar o vocabulário por meio de uma experiência interativa e intuitiva.

O projeto foi desenvolvido aplicando conceitos de design de interfaces, experiência do usuário (UX), usabilidade e desenvolvimento web.

## Objetivo

Proporcionar uma experiência educativa que combine entretenimento, reconhecimento visual, desenvolvimento do vocabulário e aprendizagem da escrita, priorizando a simplicidade e a autonomia do jogador.

## Funcionalidades

- Formação de palavras utilizando letras embaralhadas.
- Identificação de imagens inicialmente desfocadas.
- Sistema de dicas com revelação progressiva das imagens.
- Diferentes níveis de dificuldade.
- Progressão entre desafios.
- Feedback de acertos e erros.
- Interface intuitiva e amigável.
- Modo de jogo individual (singleplayer).

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` — Estrutura das interfaces do jogo.
- `styles.css` — Estilização e identidade visual.
- `game.js` — Lógica, regras e mecânicas do jogo.
- `assets/` — Imagens e recursos gráficos.

## Como executar

1. Clone ou faça o download do repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server.

## Contexto acadêmico

Projeto desenvolvido para a disciplina de **Projeto e Design de Interfaces**, integrando conhecimentos de planejamento, prototipação, design visual, experiência do usuário e implementação de interfaces interativas.
